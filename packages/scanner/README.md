# @universal-payment-qr/scanner

Camera and image QR decoding for UniPayScan. Decodes a QR code from a live camera feed or an
uploaded image into a raw payload string, ready to hand to
[`unipayscan`](https://www.npmjs.com/package/unipayscan)'s `scanner.scan()`.

Most consumers building with React should use
[`@universal-payment-qr/react`](https://www.npmjs.com/package/@universal-payment-qr/react)
instead, which wires this up for you.
